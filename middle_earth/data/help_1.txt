For this stage, the summon of the council begins with Elrond's call.

You should create a docker-compose.yaml file with the following requirements for Elrond:

- Elrond's container should log the message "Summons to the community".
- It should also create a file named 'call_timestamp.txt' in a shared volume, containing the current timestamp.
- This 'call_timestamp.txt' file must be the only file created by Elrond in that shared volume.

Note: When you run `docker-compose up -d` from the root directory (`/root/lotrdc`), your Docker Compose project will typically be named `lotrdc`. This means your Elrond container will be automatically named `lotrdc-elrond-1`. The `check_summon` command relies on this naming convention.

=== HOW TO FINISH THE STAGE ===

Once you create the docker-compose.yaml, run it in detached mode (e.g., `docker-compose up -d`).
When Elrond's container has started and logged its message, call the command 'check_summon' to verify Elrond made the call.

Whenever you need to go back to these instructions, the command 'helpme' will show this same text.
