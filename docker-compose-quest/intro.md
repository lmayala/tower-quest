# Tower Quest

Welcome to **Tower Quest**.

This is the second adventure in the series.  
After learning Docker basics in Ring Quest, you will now master **Docker Compose** while the story continues through Moria, Lothlórien, and toward Isengard.

### What you will practice
- Multi-container applications with Docker Compose
- Networks and service communication
- Scaling services
- Environment variables and secrets
- Volumes and real-world Compose patterns

### How to start
The environment is already prepared.  
Follow the on-screen instructions and use the `helpme` command when you need guidance.

The Fellowship continues.  
Your containers await.
